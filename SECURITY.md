# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting:
the **Security** tab of this repository → **Report a vulnerability**.

Include a description, affected skill(s), and steps to reproduce. We aim to
acknowledge reports within 5 business days.

## Scope

Skills are instructions and helper scripts that agents execute on a user's
machine. Reports about prompt-injection paths, unsafe shell commands in a
skill, or leaked credentials in this repository are in scope. Vulnerabilities
in the products themselves belong in their repositories:
[uteke](https://github.com/codecoradev/uteke) and
[cora-code](https://github.com/codecoradev/cora-code).
