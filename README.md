# CodeCora Agent Skills

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

Agent skills for [Uteke](https://github.com/codecoradev/uteke) and
[Cora Code](https://github.com/codecoradev/cora-code), in the layout the
[`skills`](https://www.npmjs.com/package/skills) CLI expects (`skills/<name>/SKILL.md`).

## Install

```bash
npx skills add codecoradev/skills
```
